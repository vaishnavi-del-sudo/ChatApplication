**Problem Statement**

Develop a simple Java-based real-time chat application that allows two users to communicate through a client-server connection.

**Scope**

1. Real-time text messaging using Java Socket Programming
2. Two-user client-server communication
3. Message timestamps and read receipts
4. Emoji support
5. Light/Dark mode
6. Online/offline and join/leave status
7. User-friendly Java Swing interface

**Target Users**

i. Students and beginners learning Java networking
ii. Users needing a simple two-person desktop chat application

**High-Level Features**

(a) Real-time messaging
(b) Username-based identification
(c) Message bubbles
(d) Timestamps
(e) Read receipts
(f) Emoji picker
(g) Dark/Light mode
Online/offline status
Join/leave notifications
Connection error handling
